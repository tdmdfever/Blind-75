# Blind 75

Python solutions to the "Blind 75" set of classic coding-interview problems, worked through as 2026 summer homework.

## Structure

Problems are grouped into topic units, numbered in solve order:

- **1: Sequences** — arrays, strings, and interval problems (two sum, contains duplicate, max profit, valid anagram, valid parentheses, maximum subarray, product of array except self, three sum, merge intervals, group anagrams, maximum product subarray, rotated array search)
- **2: Data Structures** — linked lists, sliding window, and grid/graph basics (reverse linked list, cycle detection, container with most water, rotated array minimum, longest substring problems, number of islands, remove nth node from end, palindromic substrings, Pacific Atlantic water flow, minimum window substring)
- **3: Nonlinear Data Structures** — trees and graphs (invert binary tree, validate BST, insert/merge intervals, construct binary tree, top K frequent elements, clone graph, task scheduler, serialize/deserialize binary tree, binary tree max path sum, max depth, same tree, level order traversal, encode/decode strings)
- **4: More Data Structures** — tries, heaps, and unions (subtree of another tree, BST lowest common ancestor, trie, trie add/search word, kth smallest element, merge sorted linked lists, median of a stream, insert interval, longest consecutive sequence, number of connected components, alien dictionary)
- **5: Dynamic Programming** — not yet started

Each problem file (`NN_problemname.py`) contains the problem statement and examples as a docstring/comment header, followed by one or more solution implementations and inline test calls.

## Running a solution

Each file runs standalone and prints its own test output:

```bash
python "1: Sequences/01_twosum.py"
```
